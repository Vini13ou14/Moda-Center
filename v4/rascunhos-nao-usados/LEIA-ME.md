# Rascunhos ainda não usados

Estes arquivos não são carregados por nenhuma página do site hoje
(nenhum `.html` tem `<link>` ou `<script>` apontando para eles) — por
isso foram tirados de `css/` e `js/` e guardados aqui, para não dar a
falsa impressão de que já fazem parte do site funcionando.

- `js/menu.js` — ponto de partida para um menu (lateral/dropdown) que
  ainda não foi implementado.
- `js/search.js` — reservado para uma busca mais completa dentro do
  catálogo (a busca que já funciona no site hoje está implementada
  direto nos arquivos de cada página, não aqui).
- `css/header.css`, `css/footer.css`, `css/components.css` — arquivos
  vazios, criados como possíveis pontos de partida para estilos
  compartilhados de cabeçalho/rodapé/componentes, mas cada página
  ainda define esses estilos no próprio CSS.

Se for continuar algum desses, é só mover o arquivo de volta para
`css/` ou `js/` e ligá-lo na página certa com `<link>`/`<script>`.
